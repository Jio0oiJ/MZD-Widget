## 三步开始

1. 安装 APK（允许「未知来源」）。
2. 打开 App 获取凭证，**三选一**：
   - **Root 一键读取（推荐）**：授权 Root，直接读官方 App 的 MMKV（`smart_car_token` / `car_id`）；需官方 App 已登录过一次。
   - **账号密码登录**：由本 App 调官方登录接口取凭证。
   - **手动填 Token**：填入自己的 token 与 carid。
3. 桌面长按 → 小组件 → 「MZD 控车」→ 拖到桌面（约 4×2）。

> 凭证只存本机、不上传。Android 12+ 请在系统设置允许「闹钟和提醒」，否则自动刷新可能被延迟。

## 小组件

- **左侧**：第一行品牌文字（内容与颜色可自定义）；第二行合并车况 `未启动 车门已锁` / `已启动 车门未锁`（常态色、警示色可自定义）；点状态区可立即手动刷新。左下角为「**一键启动+解锁**」。
- **右侧 2×2**：熄火、寻车（`ctrl=search` 闪灯鸣笛）、解锁、上锁。
- 外观：磨砂玻璃背景 30% 不透明度、按钮底板 40%，扁平线性图标；主界面「桌面组件外观设置」可改文字与颜色。

## 指令规则（v1.4 起）

**10 秒间隔只在 BLE 前台服务内部生效**（回到 v1.2 设定）：解锁与上锁共用同一个窗口，任意两条 **BLE 自动指令**之间至少间隔 10 秒；桌面按钮手动点击、一键启动+解锁都不受此窗口限制。v1.3 曾把窗口全局化并引入优先级通道，已撤销。

| 场景 | 行为 |
|---|---|
| 一键启动+解锁 | 发启动 → **固定 3 秒** → 发解锁；不依赖车况接口，不受 BLE 窗口影响 |
| BLE 自动解锁 / 上锁 | 服务内部 10 秒窗口；窗口未过则状态不翻转，动作延后不丢 |
| 桌面按钮手动点击 | 不参与 BLE 窗口 |

**为什么旧版「只启动、不解锁」**（核实结论）：旧逻辑把解锁挂在「轮询 `/car/status` 直到 `engine==3`」上。实测该接口在业务层失败时返回 `HTTP 200` + `{"status":401,"message":"无权访问或登录失效"}`，而 `Api.getStatus()` 只校验 HTTP 码，解析出 `started=null`，`Boolean.TRUE.equals(s.started)` 永远为 false；轮询里还 `catch (Exception ignored){}` 吞掉网络异常；加上 60 秒长轮询跑在 `goAsync()` 里容易被 MIUI 回收。三者任一发生，解锁都不会执行。现在改为固定 3 秒延时直接发解锁，另有 **5 秒系统精确闹钟兜底**：广播进程被回收或解锁请求失败时补发一次，带去重标记不会重复解锁；启动指令本身发送失败时不启用兜底。

## BLE 自动解锁 / 上锁

**无需配对连接**，BLE 扫描到指定设备即触发。主界面「BLE 扫描自动控车」中扫描选择设备、设置离开判定时间（默认 30 秒）、打开开关并授予蓝牙/定位/通知权限。

### 只扫选中的那一台（v1.5）

选择设备后，扫描不再是「扫全部广播再软件匹配」，而是把 **MAC + 广播设备名** 组成非空 `ScanFilter` 交给蓝牙控制器做硬件过滤，回调里只剩目标设备：

| 项 | v1.4 | v1.5 |
|---|---|---|
| 过滤 | 无过滤器，全量广播回调 | 非空 `ScanFilter`（MAC + 名称）+ 软件二次确认 |
| 扫描模式 | `SCAN_MODE_LOW_POWER`（约 10% 占空比） | `SCAN_MODE_LOW_LATENCY`（连续） |
| 上报策略 | 默认聚合上报 | `MATCH_MODE_AGGRESSIVE` + `MATCH_NUM_MAX_ADVERTISEMENT`，每次广播都上报 |
| 息屏 | 无过滤器扫描易被系统挂起 | 有过滤器，不受息屏挂起限制 |
| 失败恢复 | `onScanFailed` 只提示，扫描静默失效 | 10 秒退避重启、60 秒零回调自愈、5 分钟周期重建、蓝牙关→开自动恢复 |

硬件过滤 + 连续扫描让密集环境（商场 / 地库）的射频碰撞与回调风暴不再淹没目标设备；所有重启间隔都远大于系统的「30 秒 5 次扫描注册」配额，不会触发限流。代价是持续扫描比旧版略耗电。

> 若设备使用**随机 MAC** 且广播包里不带名称，硬件过滤可能匹配不上：在主界面重新扫描并选一次设备（更新 MAC），或改用广播里带固定名称的设备。选设备时 App 会优先读取广播包内的名称，不再只依赖系统缓存名。

- **扫到设备** → 先查车况，已解锁则跳过；否则发解锁。
- **连续 N 秒扫不到** → 已启动则不动；已锁则跳过；其余自动上锁。
- **解锁闩锁（v1.4 新增）**：本次「靠近」成功解锁（或确认车已解锁）后置位，**在下次「离开」真正发出锁车命令 / 确认车辆已锁之前，不再下发任何解锁指令**。解决开车时蓝牙一直在附近被反复扫到、不停发送解锁指令的问题。闩锁落盘保存，前台服务被系统重建也不会丢；解锁指令发送失败不置位，后续扫描会重试。
- 闩锁复位出口：① 离开发出上锁指令成功；② 离开时车况已是「已锁」；③ 用户重新打开 BLE 开关或重新选择设备（手动重置）。发动机已启动而「保持现状」时**不复位**，避免行驶中又解锁。
### 通知栏实时状态（v1.5）

常驻通知不再是固定说明。下拉展开可看到：

- **标题**：设备名 + `在附近` / `已离开`
- **信号**：最近一次 RSSI（dBm）与强 / 中 / 弱、`N 秒前可见`
- **扫描**：连续扫描中 / 蓝牙已关闭 / 失败重试中，以及过滤方式（MAC + 名称）
- **最近动作**：如「扫描到蓝牙设备，已自动解锁」「本次靠近已解锁，跳过解锁指令」及发生时间
- **车况与规则**：`未启动 车门已锁`、10 秒窗口、解锁闩锁是否已置位

连续扫描每秒可能回调数十次，通知按 3 秒节流更新，且不会重复响铃。后台扫描仍用前台服务实现，开机 / App 更新后自动恢复。

## 自动刷新

| 场景 | 间隔 |
|---|---|
| 常态周期刷新 | 每 **5 分钟** 拉取车况并同步重绘桌面 |
| 快刷（点任意桌面按钮 / 状态区 / BLE 自动动作后） | **2 秒 × 5 次** |

由系统**精确闹钟链式驱动**（`setExactAndAllowWhileIdle`），不依赖 App 进程常驻；即使进程被回收，桌面组件也会自动更新。每次刷新（含去重命中、网络失败）都会重绘，缓存同步落盘。重复触发重新计时、不叠加定时器。

## 小米 / MIUI 桌面图标

v1.2 起图标路径收敛为**单一各密度 PNG**：去掉 adaptive-icon / roundIcon / foreground 分支，图标改成整幅不透明真彩色 PNG，且 Release 关闭资源名混淆。若桌面仍显示旧图标或安卓机器人，多为 **MIUI 桌面图标缓存**：

1. **长按桌面图标 → 移除**（只删快捷方式）→ 从应用抽屉重新拖到桌面。
2. 设置 → 应用管理 → 「系统桌面 / 小米桌面」→ **清除缓存**（只清缓存，**不要点清除数据**）。
3. 主题 App → 我的 → 图标样式：临时关闭「统一图标样式」或换个样式再换回。
4. 重启手机；最后手段是卸载后重装。

## 常见问题

| 现象 | 处理 |
|---|---|
| 提示「请先获取凭证」 | 重新登录或 Root 读取一次 |
| Root 读取失败 | 确认已授权本 App Root、官方 App 已登录过 |
| 车况一直「正在获取…」 | 检查网络；token 过期就重新获取凭证 |
| 自动刷新不生效 | Android 12+ 开启「闹钟和提醒」，确认已联网、已登录 |
| 靠近后不再自动解锁 | 检查闩锁：完成一次「离开→上锁」，或重新开关 BLE 开关 |
| 通知一直显示「已离开」 | 展开通知看「扫描」行；随机 MAC 设备重新扫描选择一次；蓝牙关→开会自动恢复扫描 |

## 版本

- **v1.5** — 选好设备后**只对该设备定向连续扫描**（非空 `ScanFilter` + `LOW_LATENCY` + `AGGRESSIVE` 上报），修复扫描失败静默失效与蓝牙重开不恢复，增加自愈重启；**通知栏改为实时状态**（在附近/已离开、RSSI、扫描状态、最近动作、车况与闩锁）；选设备优先读广播包内的名称；`versionCode 6`。
- **v1.4** — 10 秒间隔退回 BLE 服务内部（撤销 v1.3 全局仲裁/优先级通道）；核实并说明一键启动不解锁的根因；新增 **BLE 解锁闩锁**，一次靠近只解锁一次，直到离开发出锁车命令才复位；`versionCode 5`。
- **v1.3** — 一键启动改为固定 3 秒延时 + 5 秒闹钟兜底；曾把 10 秒窗口全局化（v1.4 已撤销）；`versionCode 4`。
- **v1.2** — 修复小米桌面只显示默认安卓图标：移除 adaptive/roundIcon 分支、图标改整幅不透明 RGBA PNG、关闭 Release 资源名混淆；`versionCode 3`。
- **v1.1** — 按 MX-5 车头照片重绘应用图标；版本号升级并显示在界面；图标 PNG 索引压缩。
- **v1.0** — 首个公开发布：控车小组件、Root/账号/Token 三种凭证、外观自定义、精确闹钟刷新、BLE 自动控车、Debug/Release 双包。
